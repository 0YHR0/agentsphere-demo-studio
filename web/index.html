    GET CONNECTED
    连接你的 AgentSphere
    配置只保存在本机 .local 目录。API Key 不会写入前端代码、演示结果或导出文件。
    
  
    
  
    在控制台完成一次准备
    Agent Gateway 由用户手动创建。工具不会代替客户创建网关、开通权限或生成 API Key。
    1
    选择区域并开通 AgentSphere
    在华为云控制台进入 AgentSphere，确认账号已开通服务并有相应权限。网关、API 地址与模板使用同一区域。
    打开华为云控制台 ↗
    2
    创建 Agent Gateway
    在 Agent Gateway 管理中创建网关，等待就绪。从详情页复制 Gateway ID 与对应的 公网域名。网关入口地址与模板的出站网络模式是两个配置。
    3
    创建 API Key
    在 AgentSphere 的 API Key 管理中创建密钥并复制。使用有权操作本次 Gateway 和模板的 Key；不要使用 IAM AK/SK 或模型 API Key 替代。
    核对官方接入文档 ↗
    
  
    填写连接信息
    API 地址负责创建和管理资源；Gateway 地址负责进入沙箱。请核对 Gateway ID 与域名确属同一个网关。
    
  
    你的沙箱模板从哪里来？
    先选择演示方式，再填写展开的参数。保存配置不会自动创建或构建云端资源。
    选择已构建完成的模板
    适合已有 Ready 模板，希望直接演示命令、文件和暂停恢复的情况。
    现场构建需要的参数
    保存后，进入“能力演示 → 构建模板”，点击“准备并演示”提交构建。构建通常需要数分钟，可在“查看 Build 状态与日志”中查询进度。
    运行期存活探针（可选 · AgentSphere 扩展）
    readyCmd 用于就绪等待；这里的 livenessProbe 才是运行期探测。探针检测到故障后的处理行为需单独验证，不能仅凭 enabled=true 就认定会自动重启服务。
    只支持 invoke、livenessProbe。HTTP 的 path 必填；未填 protocol / port 时继承 invoke，请使用业务实际监听端口。HTTP 和 Exec 二选一；enabled=true 才启用。留空表示不传探针配置。
    沙箱有效期（可选）
    修改模板来源只影响后续新建沙箱，已创建的演示沙箱会继续复用。
